CLASSIC ARCADE WEBSITE

This starter includes a searchable game library with 30 game cards and 5 playable games:
Snake, Pong, Tic-Tac-Toe, Memory Match and Tap Dash.
Other entries are labelled COMING SOON; they are not playable yet.

PUBLISH:
1. Unzip this file.
2. Upload the CONTENTS of the folder to a GitHub repository (index.html should be at repository root).
3. Connect the repository to Cloudflare Pages.
4. Framework preset: None. No build command. Set output directory to the repository root.
5. Deploy and test the Cloudflare URL.
6. Add the deployed URL to Google Search Console if you want Google to index it.

IMPORTANT:
This is not affiliated with Poki or CrazyGames. It does not copy their catalog. Only host third-party games if you have permission or the relevant license.
